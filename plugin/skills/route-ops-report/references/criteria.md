# 운행 간격 판정 기준

> 공개된 일반 지식(버스 운영 관리 분야에서 널리 쓰이는 개념)을 바탕으로 만든 **기본값**이다. 특정 기관이나 운수사의 공식 기준이 아니다.
> 사용자가 자기 조직의 기준을 말하면 그것을 우선한다.

## 목차
1. 기본 개념
2. 간격 등급
3. 노선 전체 등급
4. 예외 처리
5. 참고 조치 예시

## 1. 기본 개념

- **배차간격(headway):** 같은 노선에서 앞차와 뒤차가 같은 정류장을 지나는 시간 간격. 승객의 평균 대기 시간은 대략 배차간격의 절반이라, 간격이 고르지 않으면 같은 대수로 운행해도 승객 체감 대기가 길어진다.
- **균등 간격:** 운행 중인 K대가 노선(정류장 N개)에 고르게 퍼져 있을 때 앞뒤 차 사이의 정류장 수(N/K). `analyze_headway`의 `ratio`는 실제 간격을 이 값으로 나눈 것이다. 1이면 이상적이다.
- **버스 몰림(bunching):** 앞차가 늦어지면 그 정류장에 승객이 더 쌓여 승하차가 길어지고 더 늦어진다. 뒤차는 태울 승객이 적어 빨라진다. 이 악순환으로 두 차가 붙어 다니게 된다. **몰림 바로 앞이나 뒤에는 거의 항상 공백이 생긴다.** 그래서 몰림과 공백은 한 쌍으로 해석한다.
- **공백:** 간격이 벌어진 구간. 그 구간 정류장의 승객은 오래 기다리고, 다음에 오는 차는 혼잡해진다.

## 2. 간격 등급

| 등급 | 조건 (`ratio` 기준) | 의미 |
|---|---|---|
| 🔴 심한 몰림 | ratio < 0.25, 또는 gapStops ≤ 1 | 사실상 두 대가 함께 다님. 뒤차는 거의 빈 차로 운행 |
| 🟡 몰림 | 0.25 ≤ ratio < 0.5 | 간격이 균등의 절반 미만 |
| 🟢 정상 | 0.5 ≤ ratio ≤ 1.5 | 운행 중 흔히 생기는 변동 범위 |
| 🟠 공백 | 1.5 < ratio ≤ 2.0 | 해당 구간 대기 시간이 눈에 띄게 늘어남 |
| 🔴 심한 공백 | ratio > 2.0 | 균등 간격의 두 배 초과. 배차 한 회가 빠진 것과 비슷 |

**근거:**
- ±50%(0.5~1.5)는 도로 상황과 승객 수 변동으로 생기는 일상적인 편차로 보고 정상으로 둔다.
- 2배를 넘으면 승객 입장에서는 "차 한 대가 결행된 것"과 체감이 같다.
- 1정류장 이내는 비율과 관계없이 같은 정류장에 연달아 도착하는 수준이라 심한 몰림으로 본다.

## 3. 노선 전체 등급

| 등급 | 조건 |
|---|---|
| 양호 | 🔴가 없고, 🟡·🟠를 합쳐 2개 이하 |
| 주의 | 🔴가 1개, 또는 🟡·🟠를 합쳐 3개 이상 |
| 개선 필요 | 🔴가 2개 이상, 또는 전체 간격의 절반 이상이 정상이 아님 |

## 4. 예외 처리

- **회차 구간(`crossesTurnaround: true`):** 종점에서 정차·대기하는 시간이 있어 정류장 간격만으로는 시간 간격을 알 수 없다. **등급을 매기지 말고** 표에 "회차 구간(판정 제외)"으로 표시한다. 다만 간격이 매우 크면(ratio > 3) "회차지 출발 조정 확인 필요"라고 언급할 만하다.
- **기점 근처:** 기점(차고지)에서 대기 중인 차는 위치 정보에 나오지 않는다. 노선 앞부분(순번 1~3)에 버스가 없거나 첫 간격이 크면 출발 대기 중일 수 있다고 적는다.
- **운행 대수가 적을 때(3대 이하):** 간격이 2개 이하라 비율이 크게 흔들린다. 등급은 매기되 "표본이 적어 참고용"이라고 밝힌다.
- **배차간격 정보 없음(`scheduledIntervalMin` 없음):** 분 추정 없이 정류장 간격과 비율로만 판정한다.
- **출퇴근 시간대와 그 밖의 시간대:** 계획 배차간격은 시간대별로 다를 수 있지만 API는 하루 대표값만 준다. 첨두시(07~09시, 18~20시 KST)에는 실제 계획 간격이 더 짧을 수 있다고 덧붙인다.

## 5. 참고 조치 예시

리포트의 "참고 조치"에 쓸 수 있는 일반적인 운행관리 기법이다. 조치를 결정하는 건 운행관리자이고, 리포트에는 **"검토해 볼 수 있다"** 정도로만 쓴다.

| 상황 | 일반적인 조치 |
|---|---|
| 몰림 | 뒤차를 정류장에서 잠시 대기시켜 간격 회복(holding). 또는 뒤차가 앞차를 앞질러 가도록 조정 |
| 공백 | 공백 앞쪽 차량의 운행 속도 조절. 기점에서 다음 차 출발 시각 조정. 예비차 투입 검토 |
| 몰림과 공백이 함께 | 몰린 두 대 중 뒤차를 대기시켜 뒤쪽 공백을 메우는 것이 기본 |
| 회차 구간 간격 이상 | 회차지 대기 시간이나 출발 간격 점검 |
| 여러 곳에서 반복 | 시간대별 배차 계획이나 운행 시간표 재검토(일회성 조치로 해결되지 않는 구조적 문제일 수 있음) |
